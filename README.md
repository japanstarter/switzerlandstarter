# SwitzerlandStarter (switzerlandstarter.com)

Calm, practical travel planning for Switzerland — SBB trains, Swiss Travel Pass, alpine routes, and all 2,113 municipalities.

- **Country:** Switzerland (Schweiz · Suisse · Svizzera)
- **Complete Municipality Coverage:** All **2,113** official cities, towns, and municipalities across **26** regions
- **Multi-Language Support:** 9 languages (`en`, `de`, `fr`, `es`, `it`, `nl`, `ja`, `ko`, `zh-tw`) with full `hreflang` alternates
- **Interactive Tools:** 14 client-side travel planning calculators & generators
- **Build:** Zero-dependency Node.js static & edge build (`node build.mjs`)
